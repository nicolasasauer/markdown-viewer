## English (en-US)

**Short description** (max. 80)

Read and edit Markdown files. Simple, offline, no ads, no tracking.

**Full description**

Basic Markdown Viewer opens .md files from your file manager, mail or any other app
and shows them nicely formatted – headings, lists, checklists, tables, code blocks,
quotes and links.

Need to change something? Switch to the editor, fix it and save straight back to
the original file. On tablets and in landscape, split view shows the editor and a
live preview side by side.

• Preview, editor and split view
• GitHub Flavored Markdown: tables, task lists, strikethrough, code
• Saves back to the file you opened, or "Save as" a new one
• Adjustable text size, light and dark theme
• Opens from "Open with" and the share sheet
• No account, no ads, no tracking, no internet permission
• Open source
