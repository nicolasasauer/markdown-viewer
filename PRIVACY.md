# Privacy Policy – Basic Markdown Viewer

*Last updated: 3 October 2026*

Basic Markdown Viewer does not collect, store or share any personal data.

- **No data collection.** The app has no account, no analytics, no ads and no
  crash reporting. It does not request the internet permission.
- **Your files stay on your device.** Files are only read when you open them
  (via "Open with", the share sheet or the system file picker) and only written
  when you save. Access goes through Android's Storage Access Framework and is
  limited to the files you choose.
- **Links.** Tapping a link in a document hands it to another app on your
  device (usually the browser). What happens there is governed by that app.

Contact: open an issue at https://github.com/nicolasasauer/markdown-viewer/issues

# Datenschutzerklärung – Basic Markdown Viewer

Basic Markdown Viewer erhebt, speichert und teilt keine personenbezogenen Daten.

- **Keine Datenerhebung.** Kein Konto, keine Statistik, keine Werbung, keine
  Absturzberichte. Die App fordert keine Internet-Berechtigung an.
- **Deine Dateien bleiben auf deinem Gerät.** Dateien werden nur gelesen, wenn du
  sie öffnest („Öffnen mit“, Teilen oder Dateiauswahl), und nur geschrieben, wenn
  du speicherst – ausschließlich die Dateien, die du auswählst.
- **Links.** Tippst du auf einen Link, wird er an eine andere App auf deinem
  Gerät übergeben (meist den Browser).
